# Attribution

The starting point for this project is [Deimos-M/DL-Virtual-Assistant](https://github.com/Deimos-M/DL-Virtual-Assistant). Its original application includes Flask routes, an ImageAI object detector, and a face-recognition camera module. The local version in this repository extends and reorganizes that application, including camera selection, coordinated camera switching, and face capture/preview/registration.

The upstream repository did not provide a license when this repository was prepared. Attribution does not itself grant permission to republish someone else's code. Confirm the upstream author's terms or publish through an authorized fork before making this derivative public.

The TinyYOLOv3 weights are provided by ImageAI and are not included here. The `face_recognition` package uses dlib models. Each dependency and model remains under its own terms.
